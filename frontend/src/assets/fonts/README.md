# Fontes da atualização Magaly Abreu

Arquivos oficiais obtidos em 13/11/2026 a partir do Google Fonts, servidos localmente por `next/font/local`. Não há requisição do navegador ao Google para carregar estas fontes.

- `CormorantGaramond-Latin.woff2`: variável, aplicação nos pesos 500–600.
- `Montserrat-Latin.woff2`: variável, aplicação nos pesos 400–600.
- As licenças SIL Open Font License correspondentes estão nos arquivos `*-OFL.txt`, obtidos no repositório oficial `google/fonts`.

Os subconjuntos Latin incluem as letras acentuadas usadas no português e a pontuação dos textos desta prévia. Para novos idiomas ou caracteres fora desse conjunto, rever a cobertura antes de reutilizar.
