# Project Overview

Última Cartada / Cartada Viva é uma aplicação web baseada em Django, Next.js e PostgreSQL para gerenciamento de um jogo terapêutico de hábitos saudáveis.

A aplicação atende dois perfis:

- ADMIN: psicóloga/admin que gerencia jogo, pacientes, grupos, cartas, rodadas, evidências e desempenho.
- PLAYER: jogador/paciente que participa das rodadas, joga cartas e envia evidências.

O produto precisa ser simples, confiável, responsivo e amigável para uso terapêutico.
