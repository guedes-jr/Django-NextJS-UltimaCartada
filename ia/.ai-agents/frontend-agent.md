# Frontend Agent

Especialista em Next.js, TypeScript e CSS Modules.

Responsável por:

- criar páginas admin/player;
- criar modais;
- centralizar services;
- manter types corretos;
- garantir UX responsiva.

Nunca deve:

- usar Tailwind;
- chamar API diretamente de forma duplicada em várias páginas;
- criar formulários de cadastro fixos na página admin;
- ignorar estados de loading/erro/sucesso.
