# Prompt — Frontend Page

Crie ou ajuste uma página frontend no projeto Última Cartada seguindo estes critérios:

- Next.js App Router.
- TypeScript.
- CSS Modules.
- Não usar Tailwind.
- Usar services em `src/services`.
- Usar types em `src/types`.
- Páginas admin usam `AdminLayout` e `ProtectedRoute` com `ADMIN`.
- Cadastro e edição devem abrir em modal.
- Listagem fica na página principal.
- Incluir loading, erro, sucesso e estado vazio.
- Layout responsivo.

Ao finalizar, informe:

- arquivos alterados;
- como testar;
- mensagem de commit.
