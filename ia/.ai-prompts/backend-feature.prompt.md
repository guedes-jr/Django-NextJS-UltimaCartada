# Prompt — Backend Feature

Implemente uma feature backend no projeto Última Cartada seguindo estes critérios:

- Django + DRF.
- Apps em `backend/apps`.
- Imports usando `apps.<app>`.
- Regras de negócio em service.
- Serializer enxuto.
- ViewSet/APIView com permissionamento explícito.
- Usar transação se alterar múltiplos models.
- Usar `select_related`/`prefetch_related` em listagens.
- Retornar mensagens de erro claras.
- Não quebrar contratos já existentes.

Ao finalizar, informe:

- arquivos alterados;
- como testar;
- mensagem de commit.
