# Command — Create Admin Page

Crie uma página admin seguindo o padrão do projeto:

- rota em `src/app/admin/<dominio>`;
- CSS Module local;
- service em `src/services`;
- types em `src/types`;
- listagem em tabela;
- botão principal no header;
- cadastro em modal;
- feedback de sucesso;
- erro no modal;
- loading e estado vazio;
- layout responsivo.
