# Command — Review Feature

Revise a feature atual considerando:

- arquitetura;
- regra de negócio;
- segurança;
- performance;
- UX;
- nomes de arquivos;
- contratos de API;
- impacto nos papéis reais, grupos de mediadores e produtos concedidos.

Entregue uma lista curta de ajustes recomendados em ordem de prioridade.
